# 真实文献检索试点 v1（2026-10-12）

本轮已实际读取 DPR、FiD、REALM 三篇官方 PDF 共 30 页，建立 20 题 AI 标注草稿和原文位置校验，运行现有 RAG3 与 RAG4 切分策略的真实模型检索。**这是一轮检索诊断，尚未完成人工金标准、生成答案、语义引用核验或 Research Agent。** 官方来源与许可依据见 [来源注记](research_corpus_sources.md)，复现命令见 [试点入口](../backend/evaluation/README.md)。

## 固定条件

- 同一组 SHA-256 固定的 PDF、同一按页解析输出、同一 20 道中文问题。
- 硅基流动 `Qwen/Qwen3-Embedding-8B`，4096 维；问题向量只生成一次并由两种策略共用，LocalVectorStore 余弦检索，Top-1/5/10，无 Reranker、查询改写或生成模型。
- RAG3 size=600、overlap=60；RAG4 child=600、parent=1800、Unicode 字符 fallback、无子片重叠。切分策略包含重叠差异，不声称已隔离父片贡献。
- RAG3 共 254 子片，RAG4 共 272 子片，实测最大子片字符数均为 600。PDF 没有版式级标题结构通道，本轮不声称已抽取论文标题层级、表格或公式。
- 每批 16，超时 30 秒，每批一次尝试；两次运行共用 80 次调用上限。费用未知，不由 Token 数推算货币费用。模型版本标签是本地实验身份，供应商未提供权重摘要，不保证未来结果逐位相同。

## 完整对照结果

指标统计 16 道有正例锚点的题；4 道证据不足题保留检索明细，拒答能力未评测，不列为通过。`anchor_span_recall` 是每道题的标注锚点完整覆盖比例，再对题取均值；不是答案正确率、引用支持率或传统按 chunk ID 计算的 Recall。

| 指标 | RAG3 | RAG4 |
| --- | ---: | ---: |
| 平均锚点覆盖 @1 | 12.50% | 25.00% |
| 平均锚点覆盖 @5 | 27.08% | 33.33% |
| 平均锚点覆盖 @10 | 33.33% | 41.67% |
| 全部所需锚点覆盖 @10 | 5/16 | 5/16 |

**当前不能据此切换默认路径。** 覆盖均值提升没有带来完整题数提升，q01 出现锚点退化；人工尚未确认等价证据与标签支持范围。第一版研究任务的“无新增事实回归、修复跨文档失败、引用支持率”等产品门槛仍未通过。

## 失败与改进明细

| 问题 | 现象 | 解释与下一步 |
| --- | --- | --- |
| q01：DPR 编码器及表示 | RAG3 @10 覆盖 1，RAG4 为 0；RAG4 高分片包含 CLS/768 的后半句 | 不能把短锚点缺失直接判成错误答案；检查句子切片边界与等价证据，优先验证有预算的父片展开 |
| q05：FiD 编码输入 | RAG3 0，RAG4 1 | 只确认指定锚点位置已命中，仍须阅读整段核对语义 |
| q09：DPR/FiD 编码比较 | 0 → 0.5，两种策略均未覆盖全部指定证据 | 检查论文范围与双来源证据完整性；不能拿单篇相似片段完成比较 |
| q12：索引更新比较 | 1/3 → 2/3，仍不完整 | 前列偏向 REALM；父片无法补出未检索到的另一论文来源，需要分文档召回/受控问题拆分诊断 |
| q14：retrieval accuracy/EM | 0 → 0.5，仍不完整 | 检索到结果表不等于指标定义，需先复核定义证据和候选范围 |
| q03/q08/q11/q15/q16 | 两种策略 @10 都未覆盖指定锚点 | 检查短锚点唯一标注是否排除合法替代证据、PDF 换行、候选排序及多来源范围；不能直接归因为模型训练不足 |

在不新增模型调用、不改原候选排名的条件下，另用现有 ChunkSet 做了一次离线父片展开诊断。@10 覆盖均值为 51.04%、完整题 7/16；q01 与 q09 的指定锚点变为完整覆盖，q12/q14 仍不足。该诊断尚未接入在线检索，也没有生成答案。上下文显著增大：q01 原子片候选 4467 字符，去重后的父片为 12709 字符，因此不能与原策略按相同上下文成本直接比较。下一切片应限制总上下文预算、去重并复核语义后再验收，不以无限增加上下文替代证据质量。
